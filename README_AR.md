# حزمة انطلاق YAS DOS

هذه نسخة أولية لموقع تعريفي بسيط ومتجاوب. الملفات:
- `index.html`: محتوى الصفحة.
- `styles.css`: الألوان والتنسيق والتجاوب مع الهاتف.
- `script.js`: تحديث سنة حقوق النشر تلقائياً.

## كيف تفتح الموقع على هاتف Android؟
1. نزّل ملف ZIP وفك ضغطه باستخدام تطبيق إدارة الملفات.
2. افتح مجلد `YAS_DOS_Starter_Kit`.
3. افتح `index.html` في المتصفح لمعاينة الصفحة محلياً. إذا لم يسمح مدير الملفات بذلك، استخدم محرر HTML موثوقاً أو ارفع الملفات إلى GitHub.

## كيف ترفعه إلى مستودع GitHub الحالي؟
1. افتح https://github.com/yasdos2002/Yasdos
2. قبل الاستبدال، احتفظ بنسخة من `index.html` القديم.
3. من المستودع اختر Add file ثم Upload files.
4. ارفع `index.html` و`styles.css` و`script.js` و`README_AR.md` إلى جذر المستودع.
5. راجع الملفات قبل الضغط على Commit changes.

## كيف تنشره مجاناً عبر GitHub Pages؟
1. افتح Settings داخل المستودع.
2. افتح Pages.
3. اختر Deploy from a branch.
4. اختر `main` ثم `/ (root)` ثم Save.
5. انتظر اكتمال النشر؛ سيعرض GitHub رابط الموقع في صفحة Pages.

## تنبيهات مهمة
- هذا قالب أولي وليس متجراً إلكترونياً ولا يتضمن دفعاً أو تسجيل دخول أو جمع بيانات.
- لا تضع كلمات مرور أو مفاتيح API داخل ملفات الموقع العامة.
- روابط Google Fonts تحتاج اتصالاً بالإنترنت؛ توجد بدائل خطوط النظام إذا أردت العمل دون اتصال.
- قبل استخدام أي قالب أو كود من GitHub تجارياً، اقرأ ملف LICENSE وشروط الأصول والخطوط والصور.
- الخطط المجانية وحدود أدوات AI قد تتغير؛ تحقق من شروط كل خدمة قبل الاعتماد عليها.
- لا توجد وعود بأرباح أو زيارات أو مبيعات؛ النجاح يعتمد على جودة المنتج ووجود طلب حقيقي.

## أول تعديل مقترح
غيّر النصوص في `index.html` لتعرض منتجاً رقمياً واحداً حقيقياً، مع وصف واضح للمشكلة التي يحلها ورابط شراء صحيح. لا تضف رابطاً وهمياً.
